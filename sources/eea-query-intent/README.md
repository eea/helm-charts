# EEA-QUERY-INTENT

Multilingual query-intent classifier for the EEA website. Decides which search queries are genuine questions, exploratory requests, or factual claims that warrant an AI-generated answer, and which are plain keyword searches.

Based on [eea-query-intent](https://github.com/eea/eea-query-intent)

Using [eeacms/eea-query-intent](https://hub.docker.com/repository/docker/eeacms/eea-query-intent/tags) docker image
